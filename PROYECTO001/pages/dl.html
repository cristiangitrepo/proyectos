Lista de definiciones

HTML
Lenguaje de marcado utilizado para estructurar contenido en la web.
CSS
Lenguaje de estilo utilizado para diseñar y dar formato a páginas web.
JavaScript
Lenguaje de programación que permite agregar interactividad a las páginas web.
CMS
Sistema de gestión de contenidos que permite crear y administrar sitios web sin necesidad de programar.
