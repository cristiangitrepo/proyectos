🚀 Coming Soon Page
A sleek, modern, and fully responsive "Coming Soon" landing page designed to build anticipation and capture early user interest before your official launch.

---
✨ Features

Countdown label: Creates urgency by displaying the exact time remaining until launch.
Responsive Design: Looks stunning and works seamlessly on desktops, tablets, and mobile devices.
Lightweight & Fast: Built with clean, optimized code for lightning-fast load times.

---

🛠️ Built With
HTML5 – For semantic and accessible structure.
CSS3 For modern, responsive styling and animations.

---

Run the project:
Open `index.html` directly in your favorite web browser, or use a live server extension (such as Live Server in VS Code) for the best development experience.
